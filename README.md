# Data Hub Extension

Personal data manager browser extension.

## Tech stack

- Manifest V3
- WXT
- React + TypeScript
- Tailwind CSS

## Commands

- `npm run dev` - start dev server
- `npm run build` - build extension
- `npm run build:zip` - build and zip
- `npm run preview` - preview

## Browser target

- Chrome first
- Validate Firefox MV3 behavior early in Sprint 1

## Cloud MVP

- Google Drive only for MVP
